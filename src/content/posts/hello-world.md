這裡是 Fearnot 的工作日誌。打 CTF、維運網路、帶社群課程的過程中，有很多「當下想通、過一個月就忘」的東西，這個部落格就是用來把它們留下來的地方。

*夜班工作桌示意照片（AI 生成），用來展示文章圖片與自有 CDN 的載入效果。*

## 會寫什麼

- **資訊安全**：CTF 解題筆記、漏洞的成因與修補。
- **網路維運**：社群活動場地的網路規劃、踩過的坑。
- **教學**：準備課程時整理的教材，以及教學現場的觀察。

## 設計

部落格延續 [fearnot.tw](https://fearnot.tw/) 的「夜班」調色盤：機房熄燈後的深色、琥珀色的狀態燈、只用細線分隔的版面。標題在進場時被游標掃描出來；首頁是一格格依年份排好的文章卡片，可以直接搜尋或用標籤篩選，滑過時卡片角落亮起一顆埠燈。

```sh
# 每篇文章都是 src/content/posts/ 底下的一個 Markdown 檔
npm run dev
```
